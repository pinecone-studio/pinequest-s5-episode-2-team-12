# ai/v2 — Суу v2 (хоёр дахь сургалт)

Нэг загвар, 5 чадвар. Апп чадварыг **system prompt**-оор сонгоно (`prompts.json`).
Эхний сургалт (Desmos хичээл, `sat_desmos_kit`) дууссаны дараа түүн дээр үргэлжлүүлж сургана.

## Файлууд

```
skills.ts     system prompt-ууд, 26 сэдвийн нэр, гарагууд (runtime import байхгүй)
planner.ts    төлөвлөгөөний дүрэм (алтан хариу), санамсаргүй сурагч, шалгагч
analyze.ts    алдааны хэв маяг (алтан хариу), санамсаргүй алдааны жагсаалт, шалгагч
stepcheck.ts  зөв бодолт → 70%-д нь нэг алдаа оруулна (тэмдэг, хаалт, хувь, налуу, квадрат, систем)
chat-extra.ts латин үсэг, ерөнхий асуулт, халдлага
export.ts     → ai/data/tuning-v2/{train,val,test}.jsonl + prompts.json
score.ts      загварын хариуг шалгана (Colab-д `bun`-аар, node_modules хэрэггүй)
```

Хариу бүрийг **код** гаргадаг тул сургалтын өгөгдөлд буруу хариу байхгүй. Шалгагч алтан хариуг 100% гэж үнэлдэг
(тест), буруу хариуг (завгүй өдөрт хичээл тавьсан, минутын нийлбэр буруу, хэв маяг алдсан) барьдаг.

## Ажиллуулах

1. `bun ai/v2/export.ts` — өгөгдөл (train 6,164 · val 546 · test 264). Код өөрчилсний дараа заавал дахин ажиллуулна
   (`bun test ai` шалгана).
2. `ai/train/suu_v2.ipynb`-ийг Colab-д нээнэ (T4) → эхний сургалтын `results.zip` ба `sat_desmos_kit.zip`-ийг upload →
   **Run all**. Тэмдэглэл: хугацааг хэмжээгүй (3B дээр ~1.5–2.5 цаг гэж тооцсон). `FAST = True` бол ~4 дахин бага өгөгдөл.
3. `suu_v2.zip` → `ollama create suu -f Modelfile`.

## Шударгаар хэлэх зүйл

- Төлөвлөгөө ба хэв маягийн алтан хариуг дүрэм гаргасан. Загвар нь өгөгдөл уншиж, монгол тэмдэглэлийг ойлгож,
  JSON зөв гаргахыг сурна. Апп загварын JSON-г `scorePlan`-тай ижил дүрмээр шалгаад, буруу бол дүрмийн төлөвлөгөө рүү
  буцах ёстой.
- Тест өгөгдөл сургалтын өгөгдөлтэй ижил генератороос (өөр seed). Бодит сурагчийн өгөгдөл дээр шалгаагүй.
- Монгол текстүүдийг монгол хэлтэй багш хянах хэрэгтэй.
