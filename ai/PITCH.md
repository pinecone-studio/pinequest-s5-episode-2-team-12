# Pitch — AI хэсэг (Анар, ~2 минут)

## 1. Асуудал (15 сек)

Хөдөөгийн сурагч SAT Math-д Desmos-ыг ашиглаж чаддаггүй — гэтэл Desmos ашиглавал олон бодлогыг 1 минутад шийднэ.
Англи хэлтэй AI багш бий, монголоор Desmos заадаг нь алга.

## 2. Бид юу хийсэн (45 сек)

- **Өөрсдийн загвар — Суу.** Qwen2.5-3B (нээлттэй, интернэтгүй ажилладаг) загварыг **2,406 Desmos хичээл** дээр
  LoRA-аар fine-tune хийсэн. Хичээл бүрийн хариуг код тооцоолж, Desmos алхмыг жинхэнэ ажиллуулж шалгасан.
- **16 Desmos арга:** огтлолцол, систем, регресс (шугаман, экспоненциал), slider, тойрог, статистик, хувь…
- **RAG:** хичээл бичихийн өмнө Суу манай 640 шалгагдсан хичээлээс хамгийн төстэй 2-ыг хардаг (vector хайлт).
  Сургалтад ороогүй 192 бодлогын 95%-д зөв аргын жишээг олдог.
- **Аюулгүй байдал:** Суу-гийн хичээл бүрийг апп шалгаад л харуулна (JSON, хариу таарах, монгол текст).
  Сурагч хариулаагүй бол хариутай алхам түгжээтэй.
- **Ажиллах газар:** Pinecone-ийн iMac дээр, токентой хаалгаар (proxy) вэбсайттай холбогдсон.

## 3. Демо (45 сек)

1. Бодлого нээх → муур **Desmos** товч → дэлгэц хоёр хуваагдаж Суу алхам алхмаар зурна.
2. Чатад "яагаад энэ шулуун?" → хариулт ижил график дээр, **"Desmos-д зурах"** товчоор нэмэлт мөр.
3. Буруу хариу бичих → "буруу" гэдгийг **код** шалгаж хэлнэ, AI таамаглахгүй.

Демогийн өмнө: `https://<site>/api/suu/status` → `"online": true` эсэхийг шалгах. Демо-д урьдчилан туршсан 3–5 бодлого.

## 4. Шударга тоо (15 сек)

| | Сургалтын өмнө (base) → дараа |
| --- | --- |
| Desmos хичээл бүрэн зөв (Colab) | → 81% |
| Вэбсайт дээр бодитоор (Ollama) | 50–62% — алдааг олж засаж байгаа (`ai/models/EVAL.md`) |

"Жижиг загвар, интернэтгүй, үнэгүй ажилладаг. Том загвар шиг төгс биш — тиймээс хариуг код шалгадаг."

## Асуулт-хариулт

- **Яагаад Gemini/GPT шууд хэрэглээгүй вэ?** — Үнэгүй, интернэтгүй (хөдөө), өгөгдөл гадагш гарахгүй. Чатад Gemini-г
  тусламж болгон ашигладаг, гэхдээ баримтыг (хариу зөв эсэх) манай код шийднэ, Desmos хичээлийг манай загвар бичнэ.
- **Fine-tune ба RAG ялгаа?** — Fine-tune: *яаж* заах (хэлбэр, монгол хэл, Desmos арга). RAG: *энэ* бодлогод тохирох
  жишээ.
- **Яагаад зарим хичээл буруу?** — 3B загвар; Colab 81% → Ollama 62% болсон шалтгааныг олсон (4-bit жингээр сурсан
  загварыг 16-bit-д нэгтгэхэд өөрчлөгддөг). Засвар бэлэн, GPU гармагц хэмжинэ.
- **Хэдэн сурагч зэрэг?** — Нэг iMac = 2 зэрэг; бусад нь жишээ хичээл авна. Цаашид сургуулийн компьютер бүр дээр.
